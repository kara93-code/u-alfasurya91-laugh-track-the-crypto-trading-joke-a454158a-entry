# Laugh Track — The Crypto Trading Joke

One line about crypto trading life (42 characters):

> I bought the dip. The dip bought a shovel.

The laugh is the reversal: the trader hunts the dip, then the dip
hunts back — with a shovel. It is true to trading life (every dip
buyer has watched the dip keep dipping) and it spends no word that
does not earn its place; the punchline lands on the last word.

`main.ts` (Node 22, standard library only) assembles the joke from
its setup and turn, checks the contest gate — UTF-8 text, 1 to 200
characters, not only whitespace — and writes it to
`/output/entry.txt` as UTF-8, mode 0644.
